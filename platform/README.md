## التشغيل على Windows (Desktop)

1. فك ضغط **`EGIC-Platform-1-app.zip`** في أي مكان على الجهاز (مثلًا على سطح المكتب). لا تحتاج أي تثبيت.
   - ملف الموديل **`EGIC-Platform-2-models-ppe.zip`** سيبه زي ما هو في مجلد التنزيلات (Downloads) أو جنب مجلد المنصة — المشغّل بيركّبه تلقائيًا أول مرة تفتح المنصة.
   - خيار «قراءة دقيقة (نموذجان)» للوحات يظهر فقط لو نموذجه متركّب (متاح في النسخة الأونلاين والنسخة الكاملة).
2. شغّل **`Install Desktop Shortcuts.bat`** مرة واحدة. هيعمل اختصارين على سطح المكتب وفي قائمة Start بأيقونة EGIC:
   - **EGIC Platform** — المنصة الحية (لوحة القيادة + الموديلات).
   - **EGIC Executive Briefing** — العرض التنفيذي التفاعلي.
3. افتح أي اختصار، والمنصة هتفتح في نافذة مستقلة (Edge أو Chrome بوضع التطبيق).
4. أول مرة تفتح الكاميرا، اضغط «السماح» (Allow).

طريقتا التشغيل (بيختار المشغّل تلقائيًا):

| الحالة | ما يحدث |
|---|---|
| **Node.js متثبت** | يشتغل الباك إند الكامل: REST API + بث مباشر (SSE) + حفظ الأدلة في `data/evidence` وسجل في `data/journal.ndjson`. تقدر تفتح المنصة من أكتر من نافذة في نفس الوقت وكلها متزامنة. |
| **Node.js مش متثبت** | سيرفر محلي مدمج بدون تثبيت وبدون صلاحيات Admin. المحرك بيشتغل داخل نافذة المنصة ويحفظ اللقطات والسجلات في تخزين المتصفح. **خلي نافذة الـ PowerShell مفتوحة طول العرض.** |

الموديلات كلها بتشتغل على الجهاز نفسه (WebGL) — مفيش أي صورة أو فيديو بيطلع برّه الجهاز.

### macOS / Linux
```bash
./start-mac-linux.sh            # يحتاج Node.js 18+
# ثم افتح: http://localhost:8080/console.html   و   http://localhost:8080/index.html
```

## سيناريو العرض المقترح

1. **العرض التنفيذي** (`EGIC Executive Briefing`)
   - اختصارات: `1–9` و`0` للفصول · `←/→` القسم التالي/السابق · `E/T` تنفيذي/تقني · `F` ملء الشاشة · `P` طباعة · `?` الاختصارات · `C` فتح المنصة.
   - `D` (أو زر ⚡ DEMO): سلسلة حدث حية — الكاميرا ← AI ← حدث ← دليل ← تنبيه ← BBS، **والحدث يتسجل فعلًا في المنصة** ويظهر في لوحة القيادة.
   - البوابة الذكية: 5 سيناريوهات (مصرح، زائر، غير مصرح، قائمة سوداء، غير مقروءة) — كل تشغيلة بتتسجل في سجل البوابات.
2. **المنصة الحية** ← «المختبر الحي» ← **تشغيل الكاميرا**
   - الموديل بيعلّم على **الخوذة والنظارة والسترة** (✓ موجودة / ✗ ناقصة).
   - لو فيه عنصر ناقص: بياخد لقطة بعلامة مائية، ويسجّل مخالفة لكل عنصر، ويضيفها مباشرة في ملف **عمر عباس (EMP-24017)** — ويظهر كل ده فورًا في لوحة القيادة وسجل الأحداث.
   - اختياري: تسجيل الوجه (بموافقة) للتعرف التلقائي — بيانات الوجه تُحفظ على الجهاز فقط.
   - وضع **ذكاء السلوك (Pose)**: إشارة استغاثة (ارفع الذراعين فوق الرأس ~1.5 ث)، سقوط، ترك محطة التشغيل (حدد المهلة)، وضعية انحناء.
3. **قراءة اللوحات المصرية (ANPR)**: 7 صور نموذجية + مقطع فيديو بوابة، أو الكاميرا/رفع صورة. النتيجة: اللوحة بالحروف العربية + القرار + تسجيل دخول/خروج ومدة البقاء. خيار «قراءة دقيقة (نموذجان)» أبطأ ويحتاج كارت شاشة أقوى.

> نصيحة قبل العرض: افتح المنصة مرة قبل الاجتماع بدقيقتين وشغّل الكاميرا مرة، عشان الموديلات تتحمّل وتسخن (أول تحميل أبطأ).

## ما هو حقيقي وما هو توضيحي

| العنصر | الحالة |
|---|---|
| كشف معدات الوقاية بالكاميرا (خوذة · نظارة · سترة) | **حقيقي** — نموذج رؤية يعمل على الجهاز |
| قراءة اللوحات المصرية | **حقيقي** — كشف اللوحة + قراءة الحروف والأرقام + قاعدة تخطيط اللوحة المصرية |
| ذكاء السلوك (SOS · سقوط · ترك محطة · وضعية) | **حقيقي** — نموذج تقدير وضعية الجسم |
| التعرف على الوجه (اختياري) | **حقيقي** — على الجهاز فقط وبموافقة |
| بيانات المواقع التسعة، الأحداث التاريخية، المركبات، المؤشرات | **بيانات عرض توضيحية** (مولدة، ومعلَّمة كذلك في الواجهة) |
| الأرقام التجارية والمخصصات | مخصصات تحليلية داخلية من DELMON — ليست عروض موردين |

## التقنية باختصار
- واجهة: HTML/CSS/JavaScript بدون أطر عمل — تعمل من `file://` أو أي استضافة ثابتة أو السيرفر المحلي.
- الباك إند: `server/server.js` (Node.js بدون أي مكتبات خارجية): `/api/v1/*` + بث مباشر `/api/v1/stream` + حفظ الأدلة.
- الذكاء الاصطناعي: TensorFlow.js (WebGL) على الجهاز — YOLO (معدات الوقاية)، YOLO-pose، كشف وقراءة اللوحات المصرية، face-api للتعرف على الوجه.
- التخزين: سيرفر EGIC الداخلي (وضع Node) أو تخزين المتصفح (IndexedDB) في الوضع المدمج.

## English — quick start
- **Windows:** unzip → run `Install Desktop Shortcuts.bat` once → open **EGIC Platform** or **EGIC Executive Briefing** from the desktop. With Node.js installed the full backend runs (REST + SSE + evidence storage); without it, a built-in local server is used and the engine runs in the app window (browser storage).
- **macOS/Linux:** `./start-mac-linux.sh` (Node.js 18+), then open `http://localhost:8080/`.
- Live AI (PPE, Egyptian ANPR, pose behaviour, optional face ID) runs fully on-device. Operational data (9 sites, history, vehicles, KPIs) is simulated and labelled as such.
