# EGIC · AI Safety & Smart Access Platform

**POWERED BY DELMON & DEV SMART X**

منصة سلامة وأمن ذكية لمصانع ومخازن EGIC. الكاميرات بتتحلّل لحظيًا وبتكشف:
- معدات الوقاية (PPE)
- **الحريق والدخان، وبيضرب إنذار وصفارة على كل الشاشات**
- **التدخين**
- السلوك: استغاثة، ووقوع، وماكينة سايبها المشغّل، ووقفة غلط
- لوحات العربيات المصرية
- الوجوه، والمناطق المحظورة

## المكونات

| المجلد | الوصف |
|---|---|
| [`platform/`](platform/) | الواجهة: لوحة القيادة، والمختبر الحي، والعرض التنفيذي. ومعاها سيرفر Node من غير أي مكتبات (REST + بث مباشر SSE + حفظ الأدلة). الموديلات بتشتغل جوه المتصفح (TF.js WebGL + ONNX Runtime WASM) |
| [`app/`](app/) | محرك الذكاء بالـ Python (FastAPI + Ultralytics): نفس الموديلات بالإضافة لموديلات أتقل للسيرفر وكاميرات RTSP، وفيه `/ppe/detect` و`/fire/detect` و`/smoking/detect` و`/pose/detect` و`/anpr/read` و`/ai/analyze` و`/ws/video-stream` |
| [`app/weights/`](app/weights/) | أوزان الموديلات اللي اخترناها |
| [`tests/`](tests/) | تيستات منطق الإنذارات والربط |
| [`docs/MODEL_SELECTION.md`](docs/MODEL_SELECTION.md) | ليه اخترنا كل موديل، بالأرقام |
| [`docs/DEPLOY.md`](docs/DEPLOY.md) | النشر على Railway و Vercel، والتجربة من الموبايل |

## تشغيل سريع (محلي)

```bash
# 1) المنصة
cd platform && node server/server.js                 # http://localhost:8080/console.html
# 2) محرك الذكاء (اختياري، لوضع «خادم EGIC AI»)
.venv/Scripts/python -m uvicorn app.main:app --port 8765    # http://localhost:8765/docs
# تيستات
.venv/Scripts/python -m pytest -q tests
```

## اللي بيحصل لما يتكشف حريق

1. الكاميرا (موبايل أو ويب كام أو فيديو) بتوصل للموديل، وهو بيكشف اللهب والدخان.
2. لازم الحريق يتأكد في 3 فريمات من آخر 5 قبل ما يتعامل كحريق.
3. بيتسجل حدث `FIRE_DETECTED · CRITICAL` ومعاه لقطة عليها علامة مائية.
4. البث المباشر بيبعته لكل الشاشات المفتوحة.
5. على كل شاشة بتطلع شاشة حمرا بتنوّر وتطفي، وصفارة إنذار، واهتزاز على الموبايل، وإشعار.
6. المشرف بيضغط «استلام»، والحدث بيتقفل في السجل.

## ما هو حقيقي وما هو توضيحي

- **حقيقي:** كل الكشف بالكاميرا، يعني PPE والحريق والتدخين والسلوك واللوحات والوجه. وكمان تسجيل الأحداث والأدلة والإنذارات.
- **توضيحي:** المواقع التسعة، والأحداث التاريخية، ومؤشرات الأداء. دي بيانات محاكاة ومكتوب عليها كده جوه الواجهة.
