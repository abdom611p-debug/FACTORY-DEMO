# النشر — Railway + Vercel

```
 📱 الموبايل / 💻 اللابتوب
        │  https
        ▼
 ┌──────────────────────┐     REST + بث مباشر (SSE)     ┌──────────────────────────┐
 │  Vercel  (platform/) │ ─────────────────────────────▶ │ Railway: egic-platform    │
 │  الواجهة + موديلات   │                                │ node server/server.js     │
 │  المتصفح (WebGL/WASM)│ ── صور (اختياري: محرك السيرفر) ▶│ Railway: egic-ai (Python) │──▶ أحداث للـ platform
 └──────────────────────┘                                └──────────────────────────┘
```

- **egic-platform:** فيه الـ API والبث المباشر لكل الشاشات، وبيحفظ صور الأدلة وسجل الأحداث. وكمان بيعرض الواجهة نفسها، يعني ينفع تفتحها من Railway مباشرة من غير Vercel.
- **egic-ai:** محرك الـ Python بالموديلات التقيلة (PPE، والحريق، والتدخين بالموديلين مع بعض، والـ Pose، واللوحات). ده اختياري، لأن الواجهة بتشغّل الموديلات على الموبايل نفسه.

## 1) Railway: سيرفر المنصة

1. ارفع الريبو على GitHub.
2. من Railway اعمل **New Project ← Deploy from GitHub repo**.
3. في الـ Service افتح **Settings**:
   - **Root Directory** = `platform`، وهو هيقرا `platform/railway.json` و `platform/Dockerfile` لوحده.
   - **Networking ← Generate Domain**.
4. اختياري، عشان الأدلة تفضل محفوظة بعد كل deploy: اعمل **Volume** على المسار `/data`، وحط المتغير `DATA_DIR=/data`.
5. اختياري: `CORS_ORIGIN=https://<your-app>.vercel.app`، عشان مفيش موقع تاني يقدر يكلّم الـ API.

اختبره: افتح `https://<platform>.up.railway.app/api/v1/health`، المفروض يرجّع `{"engine":"ONLINE"}`.

## 2) Railway: محرك الذكاء (اختياري)

1. في نفس المشروع اعمل **New Service ← GitHub repo**، واختار نفس الريبو.
   - **Root Directory** = `/`، وهيستخدم `railway.json` و `Dockerfile` اللي في الروت.
2. المتغيرات:
   - `EGIC_PLATFORM_URL=https://<platform>.up.railway.app`، عشان أحداث السيرفر توصل للوحة القيادة.
   - `CORS_ORIGINS=*`، أو دومين Vercel.
3. **Generate Domain**.
4. محتاج رام 2GB على الأقل، لأن torch على CPU مع 7 موديلات بياخدوا حوالي 1.5GB. أول build بياخد حوالي 6 دقايق.

اختبره: افتح `https://<ai>.up.railway.app/health`، المفروض كل الموديلات تبقى `true`. وفيه توثيق تفاعلي على `/docs`.

## 3) Vercel: الواجهة

1. **Add New ← Project**، واختار نفس الريبو.
2. **Root Directory** = `platform`. الـ Framework = **Other**. الـ build بيتظبط لوحده من `vercel.json`.
3. **Environment Variables:**
   - `EGIC_API_BASE` = `https://<platform>.up.railway.app`
   - `EGIC_AI_URL` = `https://<ai>.up.railway.app`، ودي اختيارية.
4. Deploy، وبعدها افتح `https://<app>.vercel.app/console.html` من الموبايل.

## 4) التجربة من الموبايل

1. افتح `https://<app>.vercel.app/console.html#/live`. لازم HTTPS عشان الموبايل يسمح بالكاميرا، و Vercel بيوفّره لوحده.
2. اختار **الحريق والدخان** أو **كشف التدخين** أو **الوضع الشامل**، وبعدها **تشغيل الكاميرا**، واسمح للكاميرا.
3. افتح لوحة القيادة على اللابتوب في نفس الوقت. أول ما الموبايل يكشف حريق أو تدخين، الإنذار والصفارة هيشتغلوا على **الشاشتين**.
   - المتصفح مش بيسمح بالصوت إلا بعد ما تضغط في الصفحة مرة، فاضغط في أي حتة على لوحة القيادة الأول.
4. **محرك الذكاء** ليه اختيارين:
   - **داخل الجهاز:** أسرع، ومفيش صور بتطلع برّه الموبايل.
   - **خادم EGIC AI:** بيستخدم الموديلات الأتقل والأدق، زي التدخين بالموديلين مع بعض.

## 📱 كاميرا الموبايل (QR)

الكاميرا اللي بيشتغل عليها النظام ممكن تبقى كاميرا الموبايل بدل كاميرا الكمبيوتر:

1. في **المختبر الحي** أو **قارئ اللوحات**، دوس على زرار **«📱 كاميرا الموبايل»**، هيظهرلك QR code.
2. اعمل سكان للكود بالموبايل، وبعدين دوس «تشغيل الكاميرا». الموبايل هيستخدم الكاميرا الخلفية.
3. الكمبيوتر هيتحوّل لوحده لكاميرا الموبايل، والموديلات تشتغل عليها: الحريق والتدخين والـ PPE والسلوك واللوحات.
4. أي كشف أو إنذار هيظهر **على شاشة الموبايل كمان**، ومعاه اهتزاز.

**إزاي بيشتغل:**
- **الطريقة الأساسية هي WebRTC:** الفيديو بيروح مباشرة من الموبايل لشاشة المنصة، 30 فريم في الثانية وتأخير أقل من ربع ثانية. السيرفر دوره إنه يوصّل الطرفين ببعض في الأول بس: `POST/GET /api/v1/cam/<session>/offer|answer`.
- **الطريقة البديلة تلقائية:** لو الشبكة منعت الاتصال المباشر، الموبايل يبعت صور JPEG على `POST /api/v1/cam/<session>/frame`، والمنصة تعرضها كبث MJPEG.

**TURN، عشان الفيديو المباشر يشتغل من أي شبكة:** بعض شبكات الموبايل بتمنع الاتصال المباشر، فبيرجع للطريقة البديلة اللي أبطأ. عشان تضمن الفيديو المباشر دايمًا، ضيف TURN server (مثلًا من metered.ca أو Cloudflare Calls) في المتغير ده:
```
EGIC_ICE_SERVERS=[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:<host>:3478","username":"<user>","credential":"<pass>"}]
```
- **على Railway:** حطه في خدمة المنصة، وسيرفر المنصة بيطلّع `config.js` منه. وفي نفس الخدمة تقدر تحط `EGIC_AI_URL` كمان.
- **على Vercel:** حطه في Environment Variables.

**HTTPS:** الموبايل مش بيسمح بالكاميرا من غير HTTPS.
- على Railway و Vercel: HTTPS موجود لوحده.
- محليًا: شغّل `bash platform/scripts/make-local-cert.sh` مرة واحدة، وبعدين أعد تشغيل السيرفر. هيشتغل كمان على `https://<IP الجهاز>:8443`، والموبايل لازم يكون على نفس الواي فاي. أول مرة هيظهر تحذير أمان، دوس «خيارات متقدمة» وبعدين «متابعة».
- لو Windows Firewall سألك، اسمح لـ Node.js على الشبكة الخاصة.

## 🌐 كاميرات IP / NVR

زرار **«🌐 كاميرا IP»** جنب «📱 كاميرا الموبايل» (في المختبر الحي وقارئ اللوحات وكاميرا الحضور)، وكمان **«ربط كاميرا IP / NVR»** في صفحة الكاميرات.

1. اكتب اسم الكاميرا ورابط البث، ودوس **«اختبار الاتصال»**. لو اشتغلت هتظهر صورة منها، وبعدين دوس **«حفظ الكاميرا»**.
2. دوس **«تشغيل»** جنب الكاميرا، والموديلات هتشتغل عليها زي أي كاميرا تانية.

أمثلة روابط:
```
Hikvision : rtsp://admin:PASS@192.168.1.64:554/Streaming/Channels/101
Dahua     : rtsp://admin:PASS@192.168.1.108:554/cam/realmonitor?channel=1&subtype=0
MJPEG     : http://192.168.1.20:8080/video        (زي تطبيق IP Webcam على أندرويد)
Snapshot  : http://admin:PASS@192.168.1.64/ISAPI/Streaming/channels/101/picture
```
لو كلمة المرور فيها `@` أو `:` اكتبها `%40` أو `%3A`.

**إزاي بيشتغل:** المتصفح مبيقدرش يفتح RTSP، فـ **السيرفر هو اللي بيتصل بالكاميرا** (Basic أو Digest auth) وبيبعت الصورة للمتصفح كـ MJPEG على `/api/v1/ipcams/<id>/mjpeg`. الكاميرا مش بتبث غير وفيه حد بيتفرج عليها، وبتقف لوحدها بعد 15 ثانية من غير مشاهدين.
- **RTSP محتاج ffmpeg على جهاز السيرفر.** على Windows نزّل ffmpeg.exe وحطه في `platform/bin/ffmpeg.exe` (أو ضيفه على الـ PATH، أو حدد مكانه في `FFMPEG_PATH`). صورة Docker بتثبته لوحدها. أما روابط MJPEG و Snapshot فمش محتاجة ffmpeg.
- **لازم الكاميرا تكون متاحة من جهاز السيرفر.** لو السيرفر شغال محليًا على شبكة المصنع، هيشوف كل الكاميرات اللي على نفس الشبكة. لو السيرفر على Railway، مش هيشوف غير الكاميرات اللي ليها IP عام أو Port Forwarding (ويفضّل من خلال VPN).
- الكاميرات بتتحفظ في `DATA_DIR/ipcams.json` **ومعاها كلمات المرور**، فالملف ده محمي من الـ git ومن الويب. والواجهة بتعرض كلمة المرور على شكل `****`.
- اختياري: `IPCAM_FPS` (الافتراضي 12) و `IPCAM_WIDTH` (الافتراضي 1280).

### 📡 كاميرات المصنع مع السيرفر الأونلاين (Railway) — وسيط الشبكة

سيرفر Railway على الإنترنت، فمش هيشوف كاميرات الشبكة اللي جوه المصنع. الحل إن **وسيط الشبكة** (`platform/agent/edge-agent.js`) يشتغل على أي كمبيوتر جوه المصنع: بيسأل السيرفر الكاميرات المطلوبة إيه، وبيقراها من الشبكة المحلية، وبيبعت الصورة للسيرفر على HTTPS. **مش محتاج تفتح أي بورت في الراوتر**، وبيشتغل حتى لو شركة النت عاملة CGNAT.

1. في المنصة الأونلاين: «🌐 كاميرا IP» ← **«+ إضافة وسيط»** ← اكتب اسمه ← دوس **«نزّل ملف التشغيل»**.
2. على كمبيوتر في المصنع، حط `EGIC-Agent.bat` في فولدر لوحده وافتحه. أول مرة هينزّل البرنامج و ffmpeg لوحده. Node.js 18+ لازم يكون متثبت، ولو مش متثبت الملف هيفتحلك صفحة تحميله.
3. أضف الكاميرا بالرابط بتاعها على شبكة المصنع، واختار **«طريقة الاتصال: عن طريق وسيط الشبكة»**. وبعدها «اختبار الاتصال» (الاختبار بيتعمل من كمبيوتر المصنع)، وبعدين «حفظ».

**ملاحظات:**
- الوسيط مش بيبعت صورة غير والكاميرا مفتوحة على المنصة، فمش بيستهلك نت المصنع على الفاضي. الافتراضي 8 فريم في الثانية بعرض 960، وتقدر تغيّرهم من `AGENT_FPS` و `AGENT_WIDTH` على Railway.
- لو عايز الوسيط يشتغل لوحده مع تشغيل الكمبيوتر، حط اختصار للملف في `shell:startup`. والملف بيعيد تشغيل الوسيط لوحده لو وقف.
- على Linux أو Raspberry Pi: `node edge-agent.js --server https://<app>.up.railway.app --key <المفتاح>`.
- المفتاح بيظهر مرة واحدة بس، وبيتحفظ على السيرفر متشفّر (`DATA_DIR/agents.json`). لو اتسرب، احذف الوسيط من المنصة واعمل واحد جديد.

## 🧑‍💼 الموظفين والحضور بالوجه

- **الموظفون والملفات:** دوس «إضافة موظف» واكتب الكود والاسم والقسم والوظيفة والموبايل والوردية. بعد الحفظ هيفتحلك تسجيل الوجه على طول: 5 لقطات من الكاميرا، وبتتحفظ بصمة الوجه (128 رقم) **على السيرفر**، فكل الشاشات والكاميرات بتتعرف على الموظف.
- **الحضور والانصراف:** أي كاميرا بتتعرف على وش موظف بتسجل ظهوره. أول ظهور في الوردية بيبقى **حضور**، وآخر ظهور بيبقى **انصراف**. والحالة بتتحسب من مواعيد الوردية: في الموعد أو متأخر أو انصراف مبكر أو غائب أو إجازة أسبوعية. المواعيد ومهلة التأخير والإجازة بتتظبط من زرار «الورديات والمواعيد». والوردية الليلية (زي 22:00–06:00) انصرافها بيتحسب على نفس اليوم.
- صفحة الحضور فيها **كاميرا حضور** تقدر تشغلها على كاميرا الجهاز أو الموبايل أو كاميرا IP، وتحطها على مدخل الموظفين. وكمان المختبر الحي بيسجل حضور أي وش يتعرف عليه.
- **Excel:** تصدير حضور اليوم، أو أي فترة لحد 92 يوم، أو شهر موظف معين من ملفه.
- الموظفين والبصمات والحضور بيتحفظوا في `DATA_DIR/registry.ndjson`، منفصلين عن بيانات التجارب.

## 🧹 مسح بيانات التجارب

زرار **«🧹 مسح البيانات»** فوق في لوحة القيادة بيمسح من السيرفر صور الأدلة وأحداث الكشف الحي وقراءات اللوحات. أما البيانات التوضيحية والموظفين والبصمات والحضور فبيفضلوا زي ما هم، إلا لو علّمت على خيار «امسح كمان كل الموظفين…». وكل الشاشات المفتوحة بتعمل reload لوحدها بعد المسح.

على أي نسخة منشورة للناس، **حط المتغير `ADMIN_TOKEN`** في خدمة المنصة على Railway. كده محدش هيقدر يمسح البيانات أو يضيف كاميرات أو يحذف موظفين غير اللي معاه الرمز، والزرار هيطلبه منك أول مرة. الحتة دي مهمة جدًا مع كاميرات IP، لأن من غير الرمز أي حد يقدر يخلي السيرفر يتصل بأي رابط.

## تشغيل محلي

```bash
# الواجهة + API
cd platform && HOST=0.0.0.0 node server/server.js          # http://localhost:8080/console.html
# محرك الذكاء
python -m venv .venv && .venv/Scripts/pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu && .venv/Scripts/pip install -r requirements.txt
EGIC_PLATFORM_URL=http://localhost:8080 .venv/Scripts/python -m uvicorn app.main:app --port 8765
# أو الاتنين بدوكر
docker compose up --build
```

> الموبايل على نفس الشبكة مش هيفتح الكاميرا على `http://192.168.x.x`، لأنه محتاج HTTPS. استخدم Vercel، أو اعمل نفق: `cloudflared tunnel --url http://localhost:8080`.
